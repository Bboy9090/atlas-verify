# Workspace search privacy and scope

This candidate rebuilds the existing authenticated saved-case search interface. It does not expand personal-data collection or external lookup capabilities. The page no longer automatically transmits every query to the external licensed-provider endpoint. The endpoint itself is unchanged and requires separate authorization, provider/privacy review and qualification. Saved-workspace results no longer display raw contacts or address fields in the search cards; existing case API response compatibility remains unchanged.

Clear and input changes invalidate the in-memory request; late responses cannot repopulate results. Authentication transitions clear visible results. Clear is not a database deletion, audit-log deletion or a guarantee that server work already started was cancelled. The backend returns no-store/private for successful workspace responses and explicitly discloses the existing 250-subject scan and 50-result limits. Stable ID ordering makes that bounded sample reproducible, not exhaustive. No probability or identity-confirmation claim is made by the UI.

Preserve existing suppression, session ownership, audit behavior, identifiers, case routes and assets. No external query, real personal record, paid provider request or production deployment is part of this verification. Browser interaction, full Next.js build, database integration, HTTP request privacy, and all other routes require separate qualification. Existing API uses GET query parameters; infrastructure logging and caching beyond response headers require separate review. No merge without owner authorization.
